# Правила проекта

- Язык общения, комментариев, сообщений движка и документации — русский. Идентификаторы в коде — английские.
- Данные только синтетические; реальные клиенты, цены и договоры в репозиторий не попадают (репозиторий публичный).
- Ядро `engine/src` (кроме `load.ts`) не зависит от Node API — оно должно работать и в браузере.
- Деньги внутри движка — целые копейки (`toKop`/`fromKop`); в данных и выводе — рубли.
- TypeScript только со стираемым синтаксисом (без enum, namespace, parameter properties): код запускается через `node` напрямую.
- Любое изменение правил расчёта сопровождается тестом в `engine/test` — тесты служат спецификацией.
- Перед коммитом: `npm test` и `npm run validate`.
- Основной репозиторий — GitHub; GitVerse — резервная копия.
