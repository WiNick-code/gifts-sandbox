Настройка акции

Здесь будет формирование акции: название, механика, охват, аудитория, сроки, ограничители и документ-основание. Интерфейс детально проработаем отдельно — страница пока каркасная.

Что уже определено в модели акции — эти поля страница будет редактировать:

название и id · механика (скидка %, скидка ₽/шт., фиксированная цена) · база расчёта (прайс или договорная цена) · охват (SKU / категория / весь ассортимент, исключения) · аудитория (клиенты / сегменты / все) · сроки действия · порог количества · приоритет · ограничители (минимальная маржа, лимит штук в заказе, бюджет) · документ ЭДО.

Пока акция задаётся JSON-файлом в rules/promos/ — по одному файлу на приказ об акциях, с проверкой npm run validate и историей изменений в git.

Форма редактирования появится после согласования интерфейса. Валидация будет той же, что у валидатора правил: ошибки блокируют публикацию, предупреждения — повод присмотреться.
